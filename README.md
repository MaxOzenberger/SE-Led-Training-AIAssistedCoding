# AI-Assisted Coding with the ArcGIS System

## Pre-work: install and setup guide

Complete every step in this guide **before** the workshop. It takes about **30-45 minutes**, most of which is downloads installing in the background. If you get stuck, reach out to Val and Adam before the workshop.

> [!IMPORTANT]
> Request GitHub Copilot access first. Approval usually clears the same day, but can take **2-3 business days**. Submit the request before installing anything, then complete the remaining setup while it processes.

## Setup guides

> [!NOTE]
> These steps are written for Windows. Platform-specific macOS instructions appear where the setup differs.

Complete the guides in order:

1. [Create a GitHub account and request Copilot access](docs/01-github-copilot-vscode-and-git.md)
2. [Set up Visual Studio Code](docs/02-visual-studio-code.md)
3. [Install Node.js, Python, and Git](docs/03-development-tools.md)
